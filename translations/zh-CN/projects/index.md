这里放了一些我这些年做过的**软件项目和小实验**。

有的是课程作业，有的是毕业设计，也有不少只是突然冒出一个想法，就顺手把它做了出来。现在回头看，它们未必都很成熟，但基本都记录了我在某个阶段对一种技术、一类系统，或者一个小问题的兴趣。


## 🌐 全栈与 Web 项目

### **同城快递配送系统**

📅 *2023 – 本科毕业设计* · [GitHub](https://github.com/BufferHund/Q3_LogisticsSystem_GradThesis)  
**关键词：** 物流 · 全栈开发 · Node.js · NLP Chatbot

这是我的本科毕业设计，一个面向同城配送场景的快递管理平台。  
前端使用 **Vue.js**，后端基于 **Node.js / Express**，数据存储使用 MongoDB，同时做了配送追踪和基础的客户服务功能。

我还接入了一个简单的 **NLP Chatbot** 来处理常见问题。现在看起来并不复杂，但这是我很早一次认真尝试把 NLP 和完整 Web 系统放到一起。

### **校园论坛**

📅 *2022 – 课程项目* · [GitHub](https://github.com/BufferHund/A1_Yunque)  
**关键词：** Web 开发 · Vue.js · Node.js

一个给校园场景做的 Web 论坛，有登录、发帖、评论和讨论串这些基本功能。

这是我第一个真正花了比较多时间做的前端项目。也是从这个项目开始，我发现自己很喜欢把一个页面从“能用”一点点磨到“看起来像个真正的产品”。

### **在线聊天室**

📅 *2022 – 计算机网络课程项目* · [GitHub](https://github.com/BufferHund/C1_Online-ChatRoom)  
**关键词：** Java · Socket · 多线程

一个用 Java Socket 从头搭起来的 Client–Server 聊天室。  
做了用户登录、私有频道和消息广播，也踩了不少并发和同步方面的坑。

这个项目让我第一次比较直观地理解，网络通信背后到底发生了什么。


## 🎮 游戏与交互项目

### **New Flappy Bird**

📅 *2024 – 个人项目* · [GitHub](https://github.com/BufferHund/New-Flappy-Bird)  
**关键词：** Unity · C# · ASP.NET

用 **Unity** 重新做了一版 *Flappy Bird*，加了排行榜、分数保存和动态难度。  
另外用 **ASP.NET** 搭了一个很轻量的后端来存储玩家分数。

## ⚡ Vibe Coding

这一部分更像是我的“小型实验区”。

大多数项目都是先有一个想法，然后借助 **AI-assisted Development** 很快把第一版做出来，再边跑边改。对我来说，Vibe Coding 最有意思的地方不是让 AI 替我写多少代码，而是它让我更愿意去碰一些原本不熟悉的技术栈。

## ✨ 回头看

这些项目现在看起来有大有小，有些很完整，有些更像一次技术练习。

但我其实很喜欢把它们都留着。它们能让我看到自己一路上是怎么从“把功能做出来”，慢慢开始关心代码结构、交互体验、部署方式，以及不同模块之间到底怎么配合。

有时候一个项目最后没有继续做下去，也不代表它没有价值。很多后来真正用上的东西，都是在这些小项目里第一次学会的。

而且直到现在，我还是很喜欢那种瞬间：一个 bug 调了很久，最后终于跑通了，然后你会觉得——好，这一晚上也算没白折腾。
